# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue** for security vulnerabilities or guard
bypasses. The plugin enforces safety boundaries; public disclosure of a
bypass could put projects using it at risk.

Report vulnerabilities privately to the repository maintainer by emailing
the address listed on the [GitHub profile](https://github.com/ultus-net/).

### What to include

- The policy number and the bypass/evasion you found
- The exact command or tool call that triggers the bypass
- Any affected versions

### Response

- You will receive an acknowledgement within 72 hours
- A fix will be prioritized and released via a patch version bump
- The bypass will be documented in the release notes once the fix is live
